Murmur

Offline voice dictation powered by local Whisper models. Hold a hotkey, speak, and your words appear — no cloud, no subscription, no mic always on.

Installation

Murmur requires Python 3.10+. The installer handles everything else — dependencies, model download, and optional AI cleanup.

Recommended: Use the one-line installer. It walks you through model selection and sets up your config automatically.

macOS

# Clone the repo
git clone https://github.com/preethamag/murmur.git
cd murmur

# Run the installer (handles everything)
./install.sh

Windows

git clone https://github.com/preethamag/murmur.git
cd murmur
install.bat

First-time setup

1

Grant Accessibility permission macOS only

On first launch Murmur shows an onboarding window explaining what's needed. Click Open Accessibility Settings, unlock the pane, find Murmur in the list, and toggle it on. Murmur detects the change and starts automatically — no restart needed.

Why it's needed: Murmur simulates Cmd+V to paste transcribed text. Without Accessibility access macOS blocks synthetic key events.
2

Grant Microphone permission

macOS will prompt for microphone access the first time you press the hotkey. Click Allow. On Windows, no extra step is needed.

3

Murmur appears in the menu bar

Look for 🎙 in the top-right menu bar (macOS) or the system tray (Windows). That icon is your status indicator — it changes as you record.

4

Try your first dictation

Click in any text field anywhere on your Mac, then hold Right Option (⌥), speak clearly, and release. The icon turns 🔴 while recording and ⏳ while transcribing. Your words appear at the cursor.

5

Adjust settings (optional)

Click the 🎙 menu bar icon → Settings to change your hotkey, model, language, microphone, or input mode. All settings take effect immediately — no restart required.

Features

🎙

Hold-to-talk (Push-to-talk)

Default mode

Hold your hotkey while speaking, release to transcribe. Recording stops the instant you let go, so there's never any silence to wait through. This is the fastest, most predictable way to dictate short bursts of text.

⏱

Tap-to-talk with auto silence detection (Mode B)

Tap the hotkey once to start recording; Murmur automatically stops when it detects a configurable period of silence (default 1.5 s). Tap again any time to stop early. Ideal for longer dictations where holding a key becomes tiring. Silence sensitivity is tunable in config.yaml.

🧠

Local Whisper transcription

All audio is transcribed on-device using OpenAI's Whisper model — nothing is sent to the internet. On Apple Silicon, Murmur automatically uses mlx-whisper for GPU-accelerated transcription; Intel Macs and Windows use faster-whisper with int8 quantisation. Six model sizes from tiny (75 MB) to large-v3 (3 GB) are available.

✨

AI cleanup requires Ollama

Optionally runs transcribed text through a local qwen2.5:1.5b LLM via Ollama to remove filler words (um, uh, like, you know), fix grammar, and polish capitalisation — turning raw dictation into clean written prose. Completely offline. Toggle in Settings → AI Cleanup.

📖

Vocabulary replacements

Define exact word substitutions that are always applied after transcription. For example: Murmur hears "dont" → types "don't", or "dave it" → "David". Rules are applied longest-match-first so phrases like "New York City" are matched before "New York". Managed via the Vocabulary menu.

🔤

Context-aware vocabulary requires Ollama

For words with multiple correct forms (e.g. "lamps / LAMS / Lams", "claude / Claude / CLAUDE"), list the alternatives and the LLM picks the right form based on surrounding sentence context. Unlike simple replacements, context words use AI to distinguish usage rather than blindly substituting.

🔁

Fix Last Transcription & auto-learn

After any dictation, click Fix Last Transcription in the menu to open a small editor showing what was typed. Make corrections and click Save — Murmur diffs your changes word-by-word and automatically adds corrected words to your Vocabulary Replacements. Your personal vocabulary grows passively as you work.

🖊

Punctuation commands

Say punctuation aloud and Murmur converts it: "comma" → ,, "period" → ., "new paragraph" → two line breaks, "open quote" / "close quote" → curly quotes, "em dash" → —, and 30+ more. Longer phrases match before shorter ones so "exclamation point" works correctly alongside "period".

🔊

Sound feedback

Optional earcon tones confirm recording start (ascending C5→E5) and stop (descending E5→C5). Tones are synthesised in-process with numpy — no audio files needed. Playback runs on a daemon thread so it never delays the hotkey response. Toggle in Settings → Sound feedback.

🎚

Microphone selector

Choose any connected input device from the Settings dropdown rather than relying on the system default. Useful if you have multiple mics — a podcast mic for dictation, a headset for calls — and want Murmur to always use a specific one regardless of your system preference.

🌐

Multi-language support

Whisper supports 99+ languages. In Settings you can pin a language (English, Spanish, French, German, Japanese, Chinese, and more) or set it to Auto-detect, where Whisper identifies the spoken language automatically. The language setting applies to transcription only — the app UI stays in English.

🔑

Configurable hotkey

Choose from Right Option (⌥), Left Option, Right Ctrl, Left Ctrl, F4, F5, or F6 as your trigger key. The hotkey listener runs on a daemon thread and listens globally — it works when any app is in focus. Changes take effect immediately when saved from Settings.

🚀

Launch at login

Toggle Launch at login in Settings to register Murmur as a login item. On macOS this writes a LaunchAgent plist and bootstraps it immediately via launchctl. On Windows it writes to the HKCU registry Run key. Disabling removes the entry and stops the background agent instantly.

⏰

Max recording duration

A configurable hard cap (default 60 seconds) stops recording automatically even if you forget to release the hotkey or silence never triggers. This prevents the audio buffer from growing indefinitely and caps RAM usage to a predictable ceiling. Adjustable in Settings → Max duration.

Vocabulary manager

Open 🎙 → Vocabulary to manage two lists:

  • Replacements — Word-for-word substitutions always applied. E.g. "dont" → "don't". Add, remove, or edit rows. Saved immediately when you click Save.
  • Context Words — Groups of alternative forms for the AI to choose between. E.g. add a group "lamps, LAMS" and the LLM will use whichever form fits the sentence. Requires AI Cleanup to be enabled.

Fixing and teaching Murmur

After dictating, if Murmur misheard something:

  1. Click 🎙 → Fix Last Transcription
  2. The window shows what was typed. Edit any mistakes directly.
  3. Click Save & Learn. Murmur diffs the changes and adds corrected words to Vocabulary Replacements automatically.

You can also make corrections directly inline (just retype the word) — Fix Last only helps if you want Murmur to remember the correction for next time.

Tips

  • Speak at a natural pace. Whisper handles normal conversational speech well; over-enunciating can hurt accuracy.
  • Start with the turbo model. It offers near-large-v3 accuracy at a fraction of the latency.
  • In tap mode, pause naturally at the end of your sentence — the 1.5 s silence window starts counting from your last word.
  • Vocabulary replacements are case-insensitive and whole-word, so "dont" won't accidentally match "don't already".
  • If Murmur consistently mishears a proper noun, add it to Vocabulary Replacements and it will always be corrected silently.

FAQs

Does Murmur send audio or text to the internet?

No. Audio is transcribed entirely on-device using local Whisper models. If AI Cleanup is enabled, text is sent to a locally running Ollama instance — still 100% offline. Nothing leaves your machine at any point.

Why does Murmur need Accessibility permission?

Murmur injects text by briefly setting your clipboard and simulating Cmd+V (macOS) or Ctrl+V (Windows). macOS requires Accessibility access to send synthetic key events to other applications. Without it, the paste step is blocked by the OS.

How much RAM does Murmur use?

The app shell itself uses ~30–50 MB. The Whisper model is loaded once into RAM on first use: tiny ≈75 MB, base ≈145 MB, turbo ≈810 MB, large-v3 ≈3 GB. Add ~1 GB if Ollama is running with qwen2.5:1.5b. The model stays in memory for the lifetime of the app so subsequent transcriptions are instant.

How long does transcription take?

On Apple Silicon with mlx-whisper and the turbo model, a 10-second clip transcribes in under 2 seconds. On Intel hardware with faster-whisper, expect 3–6 seconds for the same clip. The first transcription is slightly slower as the model loads into memory.

Can I switch models without reinstalling?

Yes. Open Settings → Model, choose a different size, and click Save. The new model downloads automatically on first use and is cached for future sessions. The old model stays cached too (in ~/.cache/huggingface/) — delete it manually if you need to free disk space.

Murmur typed in the wrong app — what happened?

Murmur injects text into whichever window has keyboard focus at the moment transcription finishes (not when you start recording). If you switch apps during the ⏳ processing phase the text will follow focus. Simply click back in the field you intended before releasing the hotkey or wait until the tray returns to 🎙.

Tap mode isn't stopping — what should I adjust?

The default silence threshold is an RMS energy value of 200. If you're in a noisy environment, background noise may keep the energy above the threshold. Lower silence_threshold in ~/.murmur/config.yaml or increase silence_duration from 1.5 seconds. You can also tap the hotkey a second time to stop manually at any point.

Does AI Cleanup change the meaning of what I said?

It's designed only to remove fillers and fix minor grammar — not rewrite meaning. The local qwen2.5:1.5b model is prompted explicitly to output only the cleaned text. If the model returns an empty result, Murmur falls back to the original transcription. That said, AI is imperfect — use Fix Last Transcription to correct and teach Murmur if cleanup ever goes wrong.

My clipboard keeps getting wiped — is that Murmur?

Murmur saves your clipboard before injecting text, then restores it immediately after. Under normal circumstances you won't notice. If something fails mid-injection (e.g. pbcopy times out), the restore still runs inside a finally block. If you notice clipboard loss, check that no other clipboard manager is competing with Murmur at the same instant.

How do I uninstall Murmur?

Quit Murmur from the menu bar, then: pip uninstall murmur. Remove config with rm -rf ~/.murmur. Disable login item first in Settings if you had it enabled. Cached Whisper models live in ~/.cache/huggingface/ — delete that folder to free disk space.
